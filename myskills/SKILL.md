# My Skills

Update the custom skills from `https://github.com/warner-benjamin/skills.git`:

- Pull or clone the repository and its submodules recursively.
- Install only top-level entries that contain `SKILL.md`.
- Follow a top-level skill symlink, such as `simple-english`.
- Do not install nested skills from `.external_resources` or other reference directories.
- Replace installed versions directly. Do not create or keep backups or temporary copies of old versions.
